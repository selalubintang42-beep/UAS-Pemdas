## Ketentuan Kolaborasi

- Setiap anggota wajib berkontribusi dalam penulisan kode program.
- Setiap anggota melakukan minimal satu commit bermakna pada setiap progress.
- Setiap fitur dikembangkan melalui branch `feature/nama-fitur`.
- Perubahan kode diajukan melalui Pull Request menuju branch `develop`.
- Pull Request diperiksa minimal satu anggota lain sebelum digabungkan.
- Branch `main` diperbarui pada setiap batas pengumpulan progress.
- Tabel kontribusi dan link Pull Request diperbarui secara berkala.
